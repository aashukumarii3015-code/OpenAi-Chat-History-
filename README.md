# OpenAI GenAI Chatbot 🤖

## 📌 Project Overview
A Python-based Generative AI chatbot integrated with the OpenAI API. Users can provide their own API key, interact with the chatbot, and manage chat history to review previous messages and maintain conversation context.

## ✨ Features
- **OpenAI API Integration:** Generates AI-powered responses.
- **User API Key:** Allows users to configure their own API key.
- **Chat History:** Stores conversation messages using Python.
- **Contextual Conversations:** Uses chat history to support ongoing conversations.
- **Interactive Chat:** Enables users to ask questions and receive responses.

## 🛠️ Technologies Used
- Python
- OpenAI API
- Chat history management

## 🎯 Project Goal
To build a simple, interactive AI chatbot that demonstrates Generative AI integration, conversation handling, and chat history management using Python.

## 🚀 Getting Started
1. Clone the repository.
2. Install the required dependencies.
3. Configure your OpenAI API key securely.
4. Run the Python application and start chatting.

## 🔐 Security
Keep API keys private. Never upload keys or sensitive chat history to a public repository.
